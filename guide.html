How OakCraft Report Studio works

Upload the week's lead exports and the studio builds the master lead and pipeline report: a one-sheet Excel file, a dashboard you can sort and filter, and a follow-up list for the sales team.

Weekly use

  1. Export the four reportsMeta leads, IndiaMART, JustDial enquiries and the Qualified pipeline file, straight from the CRM. Do not edit them.
  2. Drop them on the page togetherEach file is recognised from its columns and lands in its slot. A file that lands in "not recognised" is not one of the four exports.
  3. Check the report dateIt defaults to today. Waiting time on qualified leads is counted from this date.
  4. Generate the reportThe dashboard opens. Use Download Excel for the master file and Export filtered list on the Follow-ups page to send each salesperson their own list.

Any subset works. With only the lead files you get lead handling; with only the Qualified file you get the after-qualification sections. The Data checks page says which files were missing.

Salesperson names are cleaned to Title Case, so UJALA RAJPUT and Ujala Rajput count as one person. A blank salesperson becomes Unassigned. In the Qualified file, source Enquiry is reported as JustDial.

What each number means

Lead → qualified
Qualified ÷ all leads received.
Conv. on worked
Qualified ÷ (leads − not worked). It shows the quality of the calls actually made, so a salesperson with many untouched leads is not mistaken for a poor closer.
Worked
Leads with any status other than Created / New.
Action rate
Qualified leads that moved beyond Qualified (quotation, won, lost) ÷ all qualified leads.
Win rate
Won ÷ qualified leads in the pipeline.
Waiting
Days between Qualified On and the report date, for leads with no action.
Priority
Critical at 5+ days waiting, High at 3–4 days, Normal at 0–2 days.
Better / worse than team
On the scorecard, each rate is compared with the team total. Unassigned leads are never coloured.

The lead files and the Qualified file are different populations. The Qualified file is the CRM pipeline and can include leads qualified from enquiries older than this week, so the funnel restarts at "Qualified in pipeline".

The Excel report

One sheet, Lead Report, with sections A to M: headline KPIs, conversion funnel, salesperson scorecard, salesperson × source, source performance with the Facebook / Instagram split, after-qualification work, waiting-time buckets and customer types, six charts, findings with owners, data checks, the priority follow-up list, leads that moved after qualification and unassigned leads.

Two more tabs, Data_Leads and Data_Pipeline, hold the cleaned rows. Every number on the report is a live formula over those tabs: correct a status there and the report updates. The yellow cell next to "Report as-of" drives the waiting-time calculations.

Privacy

On GitHub Pages the studio has no server. The page downloads a Python runtime (Pyodide) once, and your files are read and analysed inside the browser tab. Nothing is uploaded. Recent reports are stored only in this browser's local storage; use Clear history on the home page to remove them.

In server mode, files are sent to the server you run, processed in memory and not written to disk.

Deploy on GitHub

  1. Create a repositoryFor example oakcraft-report-studio. Private works too if your GitHub plan allows Pages on private repositories.
  2. Push this folder
    git init
git add .
git commit -m "OakCraft Report Studio"
git branch -M main
git remote add origin https://github.com/<you>/oakcraft-report-studio.git
git push -u origin main
  3. Turn on PagesRepository → Settings → Pages → Source: GitHub Actions. The included workflow runs the tests and publishes the site on every push to main.
  4. Open the sitehttps://<you>.github.io/oakcraft-report-studio/. The first visit takes 10–20 seconds while the Python engine downloads; later visits are faster because the browser caches it.

To try it on your own computer without GitHub, run python -m http.server 8000 in this folder and open http://localhost:8000. Opening index.html by double-click does not work, because browsers block the engine files on file:// pages.

Server mode

For very large exports, or an office intranet without internet access to the Pyodide CDN, run the same app with native Python:

pip install -r requirements.txt
python server/app.py          # http://localhost:8000

The page detects the server automatically and the status pill reads "Engine ready · server". The same engine is also available on the command line:

python -m engine meta.xlsx indiamart.xlsx enquiries.xlsx qualified.xlsx -o report.xlsx --asof 2026-10-26

Troubleshooting

"Engine failed to load"

The browser could not download the Python runtime from cdn.jsdelivr.net or the Excel library from PyPI. Check the internet connection or office firewall, then reload. If the firewall cannot be changed, use server mode.

A file lands in "not recognised"

It does not have the columns of any of the four exports. Re-export it from the CRM without editing, or check that the header row is the first row of the sheet.

A salesperson appears twice

The name is spelt differently in two exports (for example "Amira Saikh" and "Amira Shaikh"). The Data checks page flags similar names; fix the spelling in the CRM.

Numbers in the Excel file show as 0 in a preview app

The report uses live formulas. Excel, Google Sheets and LibreOffice calculate them on open; some phone previewers do not. Open the file in a spreadsheet app.

Adding a new status or column

Status rules live in engine/loader.py (lead_bucket and pipe_stage), column names in the same file. Run python -m pytest after changing them.
